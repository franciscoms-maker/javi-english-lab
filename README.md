# Javi's English Lab 💻

App web interactiva para preparar la prueba de inglés **Unit 6 · Let's Connect** (6th Grade).

👉 **Úsala aquí:** https://franciscoms-maker.github.io/javi-english-lab/

## ¿Qué incluye?

- **💾 Vocabulary** — Computers & Technology (flashcards + quiz)
- **🔀 Zero Conditional** — lección + ejercicios
- **🔁 Past Passive Voice** — lección + ejercicios
- **📖 Reading** — 3 historias con preguntas de comprensión
- **🎧 Listening** — la app lee frases en voz alta y hace preguntas
- **🏆 Final Challenge** — prueba mixta con medalla

## Características

- Responsiva (celular, tablet, computador)
- Modo claro / oscuro
- Sistema de estrellas y progreso guardado en el dispositivo
- Funciona sin conexión abriendo `index.html`

---

Hecho con 💜 para Javiera. No requiere instalación: es una sola página HTML.
